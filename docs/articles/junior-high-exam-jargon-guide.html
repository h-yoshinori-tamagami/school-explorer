合不合・NN・SSって何？中学受験の塾用語・略語をまとめて解説

合不合、NN、SS、SO、育テ、基礎トレ、R4など、中学受験で飛び交う略語を塾別・場面別に整理。同じ言葉が別の意味になる注意点も解説します。

「次の合不合、どうする？」「NNの資格が取れた」「SSが始まる」——。中学受験の会話は、初めて聞く略語だらけです。しかも、同じ「SS」でも塾が変われば意味が変わることがあります。

まず覚えたいのは、略語は中学受験全体の共通語ではなく、塾ごとの方言が多いということ。意味が分からないときは「何のテスト？」「どの塾の講座？」まで確認すれば、たいてい解けます。保護者会やSNSでよく出る言葉を、場面別に整理します。

模試・テストの略語

  • 合不合（ごうふごう）：四谷大塚の「合不合判定テスト」。小6の志望校判定に使われる大規模模試です。
  • SO：SAPIX OPEN（サピックスオープン）の通称。志望校判定型や学校別など複数のテストがあり、「SOを受ける」だけでは種類が分かりません。
  • 学校別SO：特定校の出題傾向に寄せたサピックスオープン。総合偏差値が同じでも、学校別問題との相性を見る材料になります。
  • マンスリー：SAPIXのマンスリー確認テスト。直近の授業範囲の定着を確かめるテストです。
  • 基礎トレ・デイチェ：SAPIXの「基礎力トレーニング」と授業内小テスト「デイリーチェック」の通称。前者は毎日の演習、後者は理解度確認という違いがあります。
  • 組分け：結果でコースやクラスを分けるテスト。SAPIXにも四谷大塚にもありますが、出題範囲やクラスへの反映方法は同じではありません。
  • 週テ・S／C／B／A：四谷大塚の週テストと、その問題レベルを分ける4コース。コースは定期的な組分けテストで決まります。
  • 育テ：日能研の「学習力育成テスト」。授業内容の理解・定着を確認します。
  • カリテ：「カリキュラムテスト」の略。日能研の旧名称を指す場合と、現在の早稲田アカデミーのテストを指す場合があるため、塾名の確認が必要です。
  • 公開模試：塾外生も受験できる模試の総称。日能研で単に「公開」と言えば、日能研全国公開模試を指すのが一般的です。

志望校別講座・クラスの略語

  • NN：早稲田アカデミーの「何がなんでも」志望校別コース。開成、桜蔭など学校別に設置され、模試で受講資格を得る仕組みです。正式に「NN（何がなんでも）」と案内されています。
  • NNOP：NN志望校別オープン模試の通称。学校別問題への適性を見る模試で、NNの受講資格判定にも使われます。
  • SS：SAPIXでは小6後期の「難関校SS特訓（サンデー・サピックス）」。志望校別コースを軸に、日曜日に実戦力を磨きます。
  • SSクラス：早稲田アカデミーでは難関校を目指すクラス名として使われます。SAPIXのSS特訓とは別物です。「SSにいる」は塾名まで聞かないと意味を確定できません。
  • 日特：日能研の「日曜特訓」。小6では志望校別・難度別の入試対策を指す場面が多い言葉です。
  • 土特：SAPIXの「土曜志望校別特訓」。小6の土曜講座で、日曜のSSとは曜日も役割も異なります。
  • α（アルファ）：SAPIXの上位コース群。設置数や基準は校舎によって異なり、「α在籍」だけで全校舎共通の位置は分かりません。
  • M・A・TM：日能研のクラス名称。一般にMは応用、Aは標準、TMは一部校舎の最上位選抜クラスですが、設置状況は校舎で異なります。
  • 予シリ：四谷大塚の教材「予習シリーズ」の通称。提携塾や家庭学習でも広く使われます。
  • デイサピ・デイサポ：SAPIXの「デイリーサピックス」「デイリーサポート」。似た名前でも教材の役割は学年・科目で異なります。
  • 栄冠：日能研の家庭学習教材「栄冠への道」の通称。「本科」は授業用教材を指す場面が多く、家庭学習の会話では区別されます。

偏差値・判定で出てくる言葉

  • S偏差値・Y偏差値・N偏差値：順にSAPIX、四谷大塚、日能研の模試データを基にした偏差値の通称。母集団が違うため、同じ「60」でも意味は同じではありません。
  • R4：日能研で合格可能性80％を示す偏差値帯。公式にはR4＝80％、R3＝50％、R2＝20％と説明されています。
  • 持ち偏差値：一度の最高値ではなく、複数回の模試から見た普段の実力を表す俗称。計算方法に統一ルールはありません。

塾間の偏差値を比べるときは、数字をそのまま足し引きせず、中受AIの偏差値表で同じ学校・同じ入試回を横断して確認してください。

入試日程・併願で使う言葉

  • 前受け：第一志望より前の日程で受験すること。首都圏では埼玉・千葉の1月入試を指すことが多いものの、その学校が第一志望の受験生もいます。
  • サンデーショック：東京・神奈川の2月1日が日曜日になる年に、一部のキリスト教系学校が試験日をずらし、併願構造が大きく変わる現象です。
  • 午後入試：午前入試と同じ日の午後に受ける入試。移動時間と昼食、子どもの疲労まで含めた設計が必要です。

略語が分かると情報収集は速くなります。ただし、SNS上の短い言葉だけで講座や学校の価値を判断しないことも大切です。名称、対象学年、受講資格、実施時期は年度や校舎で変わり得ます。気になる言葉を見つけたら、最後は各塾の公式案内で確認しましょう。
